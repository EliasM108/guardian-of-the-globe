Guardian of the Globe

Native PC recompilation tooling for Ben 10: Protector of Earth (PS2). Pick your own disc image, build locally, play. No game files included.

Download tool View on GitHub

How it works

1

Choose your disc

Point the app at your own legally owned Europe or USA disc image. The region is detected automatically.

2

Build

The app translates the game to native code on your PC with bundled tools. This takes a few minutes, once.

3

Play

Launch in a window or fullscreen, with widescreen, language and memory card options.

FAQ

Is the game included?

No. This project ships tooling, configs and patches only. You must bring your own disc image and build locally. Never share built executables or generated code.


Quick start

Download, unzip, and run Guardian of the Globe.exe on Windows.
